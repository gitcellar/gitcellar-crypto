# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the code and the
cryptography. Harassment, personal attacks, and discriminatory language are not tolerated in
issues, pull requests, or any other project space.

Reports of unacceptable behaviour can be sent to admin@gitcellar.com. Reports are handled
confidentially by the maintainers.
